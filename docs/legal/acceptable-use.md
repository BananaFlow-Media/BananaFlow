## How Spotify links are handled

The app uses Spotify links to obtain descriptive metadata such as title,
artist, album, artwork, and duration. It then searches for and scores a separate
media source, normally YouTube or YouTube Music. It does not download Spotify
audio streams. A metadata match can be imperfect; the user should verify the
selected source and resulting tags.
