# BananaFlow user documentation

This folder separates ordinary user help from advanced/operator material.

- [`user-manual.md`](user-manual.md) — complete **end-user** reference in English; assumes no programming knowledge.
- [`user-guide-he.md`](user-guide-he.md) — complete **end-user** reference in Hebrew; assumes no programming knowledge.
- [`cli.md`](cli.md) — advanced command-line reference.
- [`spotify-proxy-api.md`](spotify-proxy-api.md) — technical contract for operators who self-host the optional Spotify **text-search** proxy.
- [`youtube-doctor-qa.md`](youtube-doctor-qa.md) — maintainer QA checklist, not ordinary end-user help.

Short task-oriented Help, FAQ, downloads and support are published on the official BananaFlow website. Developer/build/architecture/testing material belongs in `CONTRIBUTING.md`, `docs/testing/`, `docs/architecture/` and `docs/release/` rather than the user manuals.

The English and Hebrew manuals must describe the same product behavior. See [`../i18n/TRANSLATING.md`](../i18n/TRANSLATING.md).
